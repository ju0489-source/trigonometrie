Modul 1: Sinus und Kosinus am Einheitskreis

Das kannst du danach:

  • Den Aufbau des Einheitskreises und die Definition von sin(α) und cos(α) erklären.
  • Die Koordinaten eines Punktes P = (cos(α) | sin(α)) bestimmen und ablesen.
  • Die Vorzeichen von sin(α) und cos(α) in den vier Quadranten zuordnen.
  • Wichtige Exaktwerte (0°, 30°, 45°, 60°, 90°) angeben.

1. Kurz erklärt

Der Einheitskreis ist ein Kreis mit dem Radius r = 1 im Koordinatensystem mit dem Mittelpunkt (0 | 0). Ein Winkel α wird von der positiven x-Achse gegen den Uhrzeigersinn abgetragen.

Der Schnittpunkt des Winkelschenkels mit dem Einheitskreis ist der Punkt P = (cos(α) | sin(α)). Somit entspricht die x-Koordinate genau cos(α) und die y-Koordinate genau sin(α).

💡 MERKE
  • Punkt am Kreis: P = (cos(α) | sin(α))
  • Quadrant I (0°–90°): cos(α) > 0, sin(α) > 0
  • Quadrant II (90°–180°): cos(α) < 0, sin(α) > 0
  • Quadrant III (180°–270°): cos(α) < 0, sin(α) < 0
  • Quadrant IV (270°–360°): cos(α) > 0, sin(α) < 0
  • Symmetrien: sin(-α) = -sin(α), cos(-α) = cos(α)

Interaktive Veranschaulichung

cos(α) (x-Wert): 0.71
sin(α) (y-Wert): 0.71
Punkt P: (0.71 | 0.71)

Durchgerechnete Beispiele

Beispiel 1: Bestimme sin(150°) und cos(150°).

Lösung: 150° liegt im II. Quadranten. Der Bezugswinkel zur x-Achse beträgt 180° - 150° = 30°. Im II. Quadranten ist sin(α) positiv und cos(α) negativ. Somit ist sin(150°) = sin(30°) = 0,5 und cos(150°) = -cos(30°) = -√3/2 ≈ -0,866.

Typische Fehler

  • Vertauschen der Koordinaten: Beachte stets, dass cos(α) der x-Wert und sin(α) der y-Wert ist.
  • Vorzeichenfehler: Im III. Quadranten sind sowohl sin(α) als auch cos(α) negativ.

Modul 2: Das Bogenmaß

Das kannst du danach:

  • Die Bedeutung des Bogenmaßes x als Bogenlänge am Einheitskreis erklären.
  • Winkel vom Gradmaß ins Bogenmaß und umgekehrt umrechnen (360° = 2π rad).
  • Exakte Bogenmaßwerte wie π/6, π/4, π/3, π/2 zuordnen.
  • Bogenlängen mit s = r · x berechnen.

1. Kurz erklärt

Das Bogenmaß gibt die Länge des Kreisbogens am Einheitskreis (r = 1) an, der zum Winkel α gehört. Der Vollkreis (360°) entspricht dem Kreisumfang U = 2·π·r = 2π.

💡 MERKE
  • Grundrelation: 360° ≙ 2π rad ≈ 6,2832 rad
  • Gradmaß in Bogenmaß: x = α · (2π / 360°)
  • Bogenmaß in Gradmaß: α = x · (360° / 2π)
  • Bogenlänge allgemein: s = r · x (mit x im Bogenmaß)

Wichtige Exaktwerte

Gradmaß α 0° 30° 45° 60° 90° 180° 270° 360°
Bogenmaß x 0 π6 π4 π3 π2 π 3π2 2π

Interaktiver Winkel-Konverter

Rechenweg: 60° · (2π / 360°) = π/3 rad ≈ 1.0472 rad

Durchgerechnete Beispiele

Beispiel: Berechne die Bogenlänge s eines Kreisrings mit Radius r = 5 cm bei einem Winkel von α = 45°.

Lösung: Zuerst 45° in Bogenmaß umrechnen: x = 45° · (2π / 360°) = π/4 ≈ 0,7854. Dann s = r · x = 5 cm · (π/4) ≈ 3,93 cm.

Modul 3: Sinusfunktion und Kosinusfunktion

Das kannst du danach:

  • Die Entstehung von f(x) = sin(x) und g(x) = cos(x) aus dem Einheitskreis beschreiben.
  • Eigenschaften wie Definitionsbereich ℝ, Wertebereich [-1, 1] und Periode 2π benennen.
  • Charakteristische Punkte (Nullstellen, Hoch- und Tiefpunkte) angeben.
  • Die Verschiebung in x-Richtung cos(x) = sin(x + π/2) erklären.

1. Kurz erklärt

Trägt man den Winkel x auf der horizontalen Achse und den zugehörigen Wert sin(x) bzw. cos(x) auf der vertikalen Achse ab, entstehen die charakteristischen Wellengraphen.

💡 MERKE
  • Periode: p = 2π (bzw. 360°) – nach 2π wiederholt sich der Verlauf.
  • Symmetrie: sin(x) ist punktsymmetrisch zum Ursprung: sin(-x) = -sin(x). cos(x) ist achsensymmetrisch zur y-Achse: cos(-x) = cos(x).
  • Verschiebung in x-Richtung: Der Kosinusgraph entsteht aus dem Sinusgraphen durch Verschiebung um π/2 nach links: cos(x) = sin(x + π/2).

Modul 4: Die allgemeine Sinusfunktion

Das kannst du danach:

  • Die Parameterform f(x) = a · sin(b(x - c)) + d sicher anwenden.
  • Einfluss der Parameter angeben: |a| (Amplitude), b (Frequenz/Periode p = 2π/|b|), c (Verschiebung in x-Richtung), d (Mittellinie/y-Verschiebung).
  • Parameter aus gegebenen Funktionsgraphen ablesen.

1. Kurz erklärt

Jede allgemeine Sinusfunktion lässt sich durch Transformationen aus der Grundfunktion f(x) = sin(x) gewinnen.

💡 MERKE
  • a (Amplitude): Streckung/Stauchung in y-Richtung. Die Amplitude ist stets positiv: A = |a|. Ist a < 0, wird der Graph zusätzlich an der Mittellinie gespiegelt.
  • b (Periodenfaktor): Verändert die Periode: p = 2π / |b|. Für b > 1 ist der Graph gestaucht, für 0 < b < 1 gestreckt.
  • c (Verschiebung in x-Richtung um den Wert c): Verschiebung nach rechts für c > 0, nach links für c < 0. Achtung bei der Form a·sin(bx + φ): hier ist c = -φ/b.
  • d (Mittellinie): Vertikale Verschiebung. Die Mittellinie liegt bei y = d. Wertebereich: W = [d - |a|, d + |a|].

Interaktiver Parameter-Explorer

f(x) = 1.0 · sin(1.0 · (x - 0.0)) + 0.0

Durchgerechnetes Beispiel

Gegeben: f(x) = 3 · sin(2 · (x - π/4)) + 1.

Analyse: Amplitude A = |3| = 3. Mittellinie bei y = 1. Wertebereich W = [1 - 3, 1 + 3] = [-2, 4]. Periode p = 2π / 2 = π. Verschiebung in x-Richtung c = π/4 nach rechts.

Modul 5: Trigonometrische Gleichungen

Das kannst du danach:

  • Einfache Gleichungen sin(x) = k und cos(x) = k systematisch lösen.
  • Symmetrien nutzen für die zweite Grundlösung: x₂ = π - x₁ für sin(x), x₂ = 2π - x₁ für cos(x).
  • Die allgemeine Lösungsmenge durch Addition von k · 2π aufstellen.
  • Gleichungen mit innerer Transformation wie 2·sin(3x) - 1 = 0 mittels Substitution lösen.

1. Kurz erklärt

Da trigonometrische Funktionen periodisch sind, besitzen Gleichungen der Form sin(x) = k (für -1 ≤ k ≤ 1) unendlich viele Lösungen.

💡 MERKE & RECHENSCHEMA
  1. Isolieren: Bringe den Ausdruck auf die Form sin(z) = k.
  2. Grundlösung z₁: z₁ = arcsin(k) (Taschenrechner im Bogenmaß!).
  3. Zweite Lösung z₂ im Intervall [0, 2π[: Für sin(z): z₂ = π - z₁. Für cos(z): z₂ = 2π - z₁.
  4. Periodizität: z = z₁ + k·2π bzw. z = z₂ + k·2π (k ∈ ℤ).
  5. Rücksubstitution (falls z = b·(x - c)): Nach x auflösen und geforderte Intervallgrenzen überprüfen.

4 · Allgemeine Sinusfunktion: vier Parameter

f(x) = a · sin(b(x − c)) + d
  • a: Amplitude A = |a|; a < 0 → Spiegelung an der Mittellinie.
  • b ≠ 0: Periode p = 2π / |b|.
  • c: Verschiebung in x-Richtung um den Wert c. Positiv → rechts; negativ → links.
  • d: Mittellinie y = d; Wertebereich [d − |a|, d + |a|].

Beispiel: 3 · sin(2(x − π/4)) + 1

A = 3 · p = π · c = π/4 · d = 1.

Ablesen: A = (Maximum − Minimum)/2; d = (Maximum + Minimum)/2; p = Abstand zweier benachbarter Hochpunkte.

5 · Gleichungen: beide Lösungsfamilien

Für −1 ≤ q ≤ 1:

sin(x) = q: x₁ = arcsin(q), x₂ = π − x₁
cos(x) = q: x₁ = arccos(q), x₂ = 2π − x₁

Alle Lösungen: x = x₁ + k · 2π oder x = x₂ + k · 2π, k ∈ ℤ. Doppelte Lösungen nur einmal zählen.

Vorgehen: isolieren → ggf. z = b(x − c) setzen → beide Lösungen für z ermitteln → Perioden ergänzen → nach x auflösen → Intervall prüfen.

Beispiel: cos(x) = 0,5 → x₁ = π/3, x₂ = 5π/3 im Intervall [0, 2π[.

Taschenrechner bei Bogenmaß auf RAD stellen.
